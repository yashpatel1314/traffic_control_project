4-WAY TRAFFIC CONTROL SYSTEM - CIRCUIT DIAGRAM
================================================

This file covers wiring for BOTH sketches.
The enhanced build reuses pins 7-12 for the LCD and moves crosswalk
signals to analog pins, so the two builds are NOT pin-compatible.

════════════════════════════════════════════════════════════════════════
BASIC BUILD  —  traffic_control.ino
════════════════════════════════════════════════════════════════════════

ARDUINO CONNECTIONS:
===================

Traffic Lights (North-South):
- NS_RED (Pin 2) → 220Ω Resistor → Red LED → GND
- NS_YELLOW (Pin 3) → 220Ω Resistor → Yellow LED → GND
- NS_GREEN (Pin 4) → 220Ω Resistor → Green LED → GND

Traffic Lights (East-West):
- EW_RED (Pin 5) → 220Ω Resistor → Red LED → GND
- EW_YELLOW (Pin 6) → 220Ω Resistor → Yellow LED → GND
- EW_GREEN (Pin 7) → 220Ω Resistor → Green LED → GND

Crosswalk Signals (North-South):
- NS_CROSSWALK_STOP (Pin 8) → 220Ω Resistor → Red LED → GND
- NS_CROSSWALK_GO (Pin 9) → 220Ω Resistor → Green LED → GND

Crosswalk Signals (East-West):
- EW_CROSSWALK_STOP (Pin 10) → 220Ω Resistor → Red LED → GND
- EW_CROSSWALK_GO (Pin 11) → 220Ω Resistor → Green LED → GND

Input Buttons:
- NS_BUTTON (Pin 12) → Push Button → GND (with internal pullup)
- EW_BUTTON (Pin 13) → Push Button → GND (with internal pullup)
- EMERGENCY_BUTTON (Pin A0) → Push Button → GND (with internal pullup)

POWER:
- Arduino 5V → Breadboard power rail
- Arduino GND → Breadboard ground rail

════════════════════════════════════════════════════════════════════════
ENHANCED BUILD  —  traffic_control_enhanced.ino
════════════════════════════════════════════════════════════════════════

Pins 7-12 are claimed by the LCD in 4-bit mode.
Crosswalk LEDs and buttons move to analog pins.
EW_GREEN moves to pin 13.

Traffic Lights (North-South):
- NS_RED (Pin 2) → 220Ω Resistor → Red LED → GND
- NS_YELLOW (Pin 3) → 220Ω Resistor → Yellow LED → GND
- NS_GREEN (Pin 4) → 220Ω Resistor → Green LED → GND

Traffic Lights (East-West):
- EW_RED (Pin 5) → 220Ω Resistor → Red LED → GND
- EW_YELLOW (Pin 6) → 220Ω Resistor → Yellow LED → GND
- EW_GREEN (Pin 13) → 220Ω Resistor → Green LED → GND

16x2 LCD (HD44780, 4-bit mode):
- LCD RS  (Pin 7)
- LCD EN  (Pin 8)
- LCD D4  (Pin 9)
- LCD D5  (Pin 10)
- LCD D6  (Pin 11)
- LCD D7  (Pin 12)
- LCD VSS → GND
- LCD VDD → 5V
- LCD V0  → Wiper of 10kΩ pot (contrast adjustment)
- LCD RW  → GND
- LCD A   → 5V (backlight +, via 220Ω)
- LCD K   → GND (backlight -)

Crosswalk Signals (North-South):
- NS_CROSSWALK_STOP (Pin A1) → 220Ω Resistor → Red LED → GND
- NS_CROSSWALK_GO (Pin A2) → 220Ω Resistor → Green LED → GND

Crosswalk Signals (East-West):
- EW_CROSSWALK_STOP (Pin A3) → 220Ω Resistor → Red LED → GND
- EW_CROSSWALK_GO (Pin A4) → 220Ω Resistor → Green LED → GND

Input Buttons:
- NS_BUTTON (Pin A5) → Push Button → GND (with internal pullup)
- EW_BUTTON (Pin A6) → Push Button → GND (with internal pullup)
- EMERGENCY_BUTTON (Pin A0) → Push Button → GND (with internal pullup)
- NIGHT_MODE_BUTTON (Pin 1/TX) → Push Button → GND  ← see NOTE below
- SPEAKER_PIN (Pin 0/RX) → Passive buzzer → GND     ← see NOTE below

NOTE: Pins 0 (RX) and 1 (TX) are the hardware serial lines.
Using them while Serial.begin(9600) is active causes conflicts.
For serial debugging AND audio/night-mode, move SPEAKER_PIN and
NIGHT_MODE_BUTTON to any unused digital pin (e.g. A6/A7 are
analog-input only on the Uno, so pick a free digital pin instead).

POWER:
- Arduino 5V → Breadboard power rail
- Arduino GND → Breadboard ground rail

COMPONENT LIST
════════════════════════════════════════════════════════════════════════

Basic Build (traffic_control.ino):
- 1x Arduino Uno (or compatible)
- 1x Breadboard (830 tie points recommended)
- 1x Jumper wire kit (male-male, male-female)
- 10x 220Ω Resistors (for LED current limiting)
- 3x Push buttons (momentary, normally open)
- 6x LEDs (2x Red, 2x Yellow, 2x Green for traffic lights)
- 4x LEDs (2x Red, 2x Green for crosswalk signals)
- 1x USB cable (for programming and power)

Additional components for Enhanced Build (traffic_control_enhanced.ino):
- 1x 16x2 LCD display (HD44780 compatible)
- 1x 10kΩ potentiometer (LCD contrast)
- 1x Passive buzzer or small speaker
- 1x Extra push button (night-mode toggle)
- 4x Additional 220Ω resistors

Optional (both builds):
- 1x 9V Battery + connector (for standalone operation)
- 1x 9V to 5V voltage regulator (if using battery)
- 1x Project box/enclosure

PHYSICAL LAYOUT SUGGESTIONS:
===========================

1. Traffic Light Layout (4 corners of intersection):
   - Each corner: Red LED (top), Yellow LED (middle), Green LED (bottom)
   - Mount on small posts or cardboard cutouts

2. Crosswalk Signals:
   - Place near each crosswalk
   - Red LED (hand symbol) and Green LED (walking person symbol)
   - Can use cardboard cutouts with LED symbols

3. Pedestrian Buttons:
   - Mount on posts near crosswalks
   - Label clearly: "Push to Cross"

4. Emergency Button:
   - Mount in accessible location
   - Label: "Emergency Override"

TIMING SEQUENCE:
===============

Normal Operation Cycle (Total: ~40 seconds):
1. NS Green, EW Red (15 seconds)
2. NS Yellow, EW Red (3 seconds)  
3. All Red (2 seconds)
4. EW Green, NS Red (15 seconds)
5. EW Yellow, NS Red (3 seconds)
6. All Red (2 seconds)
7. Repeat...

Crosswalk Features:
- Buttons extend green time by 10 seconds
- Flashing warning during last 3 seconds
- Only works during appropriate green phase

Emergency Mode:
- All lights flash red
- Overrides normal operation
- Press emergency button again to resume
